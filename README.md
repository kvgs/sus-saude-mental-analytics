# 🧠 Análise de Internações Psiquiátricas no SUS
**Estado de São Paulo | 2020–2023**

## Motivação
A saúde mental é uma das áreas mais negligenciadas da saúde pública brasileira.
Este projeto analisa 331.528 internações psiquiátricas no SUS paulista entre 2020 e 2023,
período que inclui a pandemia de COVID-19 e seus impactos na saúde mental da população.

## Fonte dos Dados
DATASUS — Sistema de Informações Hospitalares (SIH)
Grupo RD (AIH Reduzida) — Estado de São Paulo
